# Lock badge previews

Generated by `tools/lock-icons/generate.ps1` from the committed **.ico** assets (not from the owner mockup).
`document-*` is the `.dwenc` document badge; `folder-*` is the standard yellow folder badge used by the
folder `desktop.ini`.

- `*-white-48.png`, `*-dark-48.png`: 48 px on white/dark Explorer backgrounds.
- `*-white-256.png`, `*-dark-256.png`: 256 px, same backgrounds.

Compared manually with `Downloads/DropWheel_1/_reference/lock-badge-mockup.jpg` (not committed):
two-tone purple body (#A012D8 left / #6A0DA8 right), lavender highlight, thick round shackle, white
keyhole, bottom-left, about 40–45% of the icon height, no blur or drop shadow. The yellow folder and
document page stay recognisable.

The `.dwenc` DefaultIcon is the document variant because Windows permits one DefaultIcon per file
extension. The original type is composed from the file's shell icon in the Lock window/preview; a
per-file Explorer icon would require a shell icon handler, which this tool deliberately does not install.
