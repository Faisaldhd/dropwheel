# DropWheel

**تحويل ملفات بلا نقرات على Windows.** أمسك بملف، واضغط مفتاحًا أثناء سحبه، ثم أفلته على صيغة في عجلة
شعاعية. كل شيء يعمل محليًا؛ لا تغادر ملفاتك جهازك أبدًا.

يعتمد DropWheel على [FileAction](https://github.com/Metamorfolog/file_action) من Metamorfolog (رخصة MIT).
هذه نسخة مستقلة لنظام Windows من الفكرة، وليست تابعة لـ Tangerine.

> النسخة الإنجليزية: [README.md](README.md). المصطلحات العربية موحّدة في
> [docs/glossary-ar.md](docs/glossary-ar.md)، وقائمة مراجعة النصوص في
> [docs/ar-strings-review.md](docs/ar-strings-review.md).

## كيف يعمل

1. أمسك بملف: من مستكشف الملفات، أو على سطح المكتب، أو صورة أو رابطًا في المتصفح، أو مرفق بريد، أو ملفًا
   داخل مجلد ZIP…
2. أثناء السحب، **اضغط** مفتاحًا:

   | المفتاح | العجلة | ما تقدّمه |
   |---|---|---|
   | **Shift** | تحويل | JPG، PNG، WebP، MP4، MP3، DOCX، PDF، XLSX… حسب نوع الملف |
   | **Ctrl** | الأدوات | ضغط، تصغير، تدوير، اقتصاص، دمج، تقسيم، إنشاء أرشيف… |
   | **Alt** | الإجراءات | نسخ إلى…، نقل إلى…، نسخ المسار، الطرفية، الرف العائم، مشاركة |

3. أفلت الملف على أحد قطاعات العجلة. تُحفظ النتيجة بجوار الملف الأصلي (ولا يتغيّر الأصل أبدًا). الإفلات في
   وسط العجلة يلغي العملية.

تبقى العجلة مفتوحة حتى تُفلت الملف، فيمكنك إفلات المفتاح والضغط على مفتاح آخر لتبديل العجلة. يمكن تغيير
المفاتيح من الإعدادات.

**تكرار آخر إجراء:** اضغط المفتاح نفسه مرة أخرى أثناء السحب (أو اضغط **R** والعجلة مفتوحة)، فتتحول العجلة
إلى قطاع واحد يكرّر ما فعلته آخر مرة بالإعدادات نفسها (مثل أوقات الاقتصاص ذاتها).

**عجلتك الخاصة:** من **الإعدادات ← تخصيص العجلات** يمكنك وضع نجمة على القطاعات المفضّلة (تأتي دائمًا أولًا
وفي المكان نفسه)، وإخفاء ما لا تستخدمه.

**بدون ماوس:** حدّد ملفات في مستكشف الملفات، أو انسخ ملفًا أو لقطة شاشة (**Win + Shift + S**)، ثم اضغط
**Ctrl + Alt + Space**. الأسهم تختار قطاعًا، وEnter ينفّذه، وTab يبدّل العجلات، وEsc يغلق، والأرقام 1–9
تنفّذ قطاعًا مباشرة.
يمكنك أيضًا فتح العجلة بالنقر بزر الماوس الأيمن ← **DropWheel…** (في Windows 11 تحت «إظهار مزيد من الخيارات»).

يظهر تقدّم العمل في زاوية الشاشة، ومن هناك يمكنك فتح النتيجة أو إظهارها في مجلدها أو إلغاء العملية.

## ما الذي يحوّله

| النوع | من | إلى |
|---|---|---|
| الصور | JPG، PNG، WebP، HEIC، TIFF، AVIF، BMP، GIF، ICO، SVG | JPG، PNG، WebP، AVIF، TIFF، ICO، PDF (وGIF ← MP4/WebM) |
| الصوت | MP3، M4A، AAC، WAV، FLAC، OGG، Opus، AIFF، WMA | MP3، M4A، WAV، FLAC، OGG، Opus، AIFF |
| الفيديو | MP4، MOV، MKV، WebM، AVI، WMV، FLV، MPG، 3GP، TS | MP4، MOV، MKV، WebM، GIF، MP3 |
| PDF | PDF | DOCX، JPG، PNG (كل الصفحات بدقة 300 DPI)، PPTX، TXT، MD، HTML، EPUB |
| المستندات | DOCX، DOC، ODT، RTF، MD، TXT، HTML، EPUB | DOCX، PDF، ODT، MD، HTML، TXT، EPUB، RTF |
| العروض | PPTX، PPT، ODP | PDF، PNG، JPG (كل الشرائح)، PPTX، ODP |
| الجداول | XLSX، XLSM، XLS، ODS، CSV، TSV | XLSX، CSV، TSV، ODS، PDF |
| الترجمات | SRT، VTT | SRT، VTT، TXT |
| الأرشيفات | ZIP، TAR، TAR.GZ، GZ، BZ2، XZ، RAR، 7z | استخراج، ZIP، TAR، TAR.GZ |

**الأدوات (Ctrl):**
- الصور: ضغط، تصغير إلى 50 %، بحد أقصى 1920 بكسل، تدوير، انعكاس، اقتصاص إلى مربّع، تدرّج رمادي، إزالة
  البيانات الوصفية (GPS، EXIF)، دمج في PDF،
- الفيديو: ضغط (H.264)، 720p، كتم الصوت، اقتصاص بالوقت، تدوير، سرعة مضاعفة، إطار مصغّر،
- الصوت: ضغط، تطبيع مستوى الصوت، اقتصاص، ضم،
- PDF: دمج، تقسيم إلى صفحات، تدوير، تحسين،
- الصور وملفات PDF الممسوحة ضوئيًا: **استخراج النص (OCR)** بمحرّك التعرّف المدمج في Windows؛ يُحفظ النص
  كملف ‎.txt‎ ويُنسخ إلى الحافظة،
- أي شيء، بما في ذلك المجلدات: إنشاء أرشيف ZIP أو TAR.GZ.

ما ليس ملفًا بعد (صورة مسحوبة من المتصفح، أو مرفق Outlook، أو لقطة شاشة في الحافظة) يُحفظ أولًا في
**Downloads\DropWheel**، وتُحفظ النتائج بجواره.

عند تحديد عدة ملفات، يُحوَّل كل ملف على حدة؛ أما الأدوات مثل «دمج» فتُنتج نتيجة واحدة.

### البرامج المساعدة

يتولّى DropWheel الصور وملفات PDF والجداول والترجمات والأرشيفات بنفسه. بعض الصيغ تحتاج برامج إضافية:

- **FFmpeg** (للصوت والفيديو، 34 ميغابايت) و**Pandoc** (للمستندات، 35 ميغابايت) يُنزَّلان عند أول حاجة
  إليهما: تظهر قطاعاتهما باهتة مع عبارة «احصل على FFmpeg»، وإفلات ملف هناك يسأل مرة واحدة ثم ينزّل
  الأداة (بعد التحقق من بصمة SHA-256 المنشورة) ويشغّل التحويل. وإذا كانتا مثبّتتين لديك (مثلًا عبر
  `winget install Gyan.FFmpeg`) يستخدمهما DropWheel مباشرة،
- **LibreOffice** (لتحويل DOC وPPTX وODS والمستندات والجداول إلى PDF) يجب تثبيته منفصلًا:
  `winget install TheDocumentFoundation.LibreOffice`.

تعرض **الإعدادات ← البرامج المساعدة** ما هو مفقود، ويمكنها تنزيله أو تثبيته لك. إبقاء الأدوات خارج حزمة
التثبيت يحافظ على حجمها أقل من 50 ميغابايت.

## التثبيت

ابنِه بنفسك (انظر أدناه) وشغّل `DropWheel.exe`؛ مجلد محمول هو كل ما يحتاجه. لا يُنشر المثبّت في أي مكان:
هذه نسخة مستقلة.

يتحدث التطبيق الإنجليزية والعربية، ويعمل بالوضعين الفاتح والداكن؛ كلاهما يتبع إعدادات Windows، ويمكن تبديل
اللغة من الإعدادات. أما اتجاه الواجهة (RTL) فيُفعَّل مع العربية.

عند أول تشغيل يضيف DropWheel نفسه إلى بدء التشغيل وإلى قائمة سياق مستكشف الملفات (ويمكن إيقاف الاثنين من
الإعدادات). ثم يقيم في علبة النظام بجوار الساعة.

المتطلبات: Windows 10 (‏1809 أو أحدث) أو Windows 11، بمعمارية x64.

## لينكس

هذه النسخة (fork) خاصة بـ Windows ولا تنشر ملفات لينكس التنفيذية. مشروع `src/FileAction.Linux` موجود في
المستودع للاطلاع فقط.

## البناء من المصدر

```powershell
# .NET 10 SDK
./scripts/fetch-tools.ps1                      # ينزّل ffmpeg.exe وpandoc.exe إلى .\tools (للاختبارات)
$env:PATH = "$PWD\tools;$env:PATH"; dotnet test tests/FileAction.Tests
dotnet publish src/FileAction.App -c Release -r win-x64 --self-contained -o publish
publish\DropWheel.exe
```

‏`DropWheel.exe --self-test <folder>` يبني كل النوافذ خارج الشاشة ويحفظ صور PNG معاينة بالإنجليزية
والعربية (يستخدمه CI).

## بنية المشروع

```
src/FileAction.Core     التحويلات والأدوات (مكتبة متعددة المنصات، تُختبر أيضًا على لينكس)
  Backends/             ImageMagick وFFmpeg وPandoc وLibreOffice وPDF والجداول والترجمات والأرشيفات
  Operations/Catalog.cs كل قطاع في عجلتي التحويل والأدوات
  Loc.cs                نصوص الإنجليزية والعربية (جداول JSON مضمّنة في Strings/)
src/FileAction.Linux    تطبيق لينكس (Avalonia): منطقة الإفلات والعجلة وسطر الأوامر وتكامل مدير الملفات
src/FileAction.App      تطبيق Windows (WPF)
  Input/GlobalInput.cs  خطافات الماوس ولوحة المفاتيح العامة (إيماءة «السحب + الضغط»)
  Wheel/                القائمة الشعاعية ووقت ظهورها
  Actions/              عجلة الإجراءات والرف العائم والمشاركة
  Jobs/                 المهام الخلفية وبطاقات التقدّم
  Shell/                أيقونة علبة النظام والاختصار وقائمة السياق والنسخة الواحدة
tests/FileAction.Tests  اختبارات وحدة واختبارات تكامل تشغّل كل عملية على ملفات نموذجية
installer/              Inno Setup
```

## الفروق عن Tangerine

- ‏Shift / Ctrl / Alt بدل Shift / Command / Control.
- صيغ Apple (Pages وKeynote وRTFD) وكتابة HEIC غير مدعومة؛ يمكن فتح HEIC.
- تحويل PDF ← DOCX/EPUB/HTML يحوّل النص لا تخطيط الصفحة الحرفي (استخدم PDF ← PPTX أو الصور لذلك).
- إجراء «AirDrop» في Tangerine يقابله **مشاركة** في Windows (المشاركة القريبة، Teams، البريد…).
